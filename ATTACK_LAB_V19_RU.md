# Attack Lab v19 — полировка K / L

База: полный локальный v18. На боевом стенде T нажмите F4 (или «Атаки / F4»). F3 и F4 используют один общий темп воспроизведения; панели открываются по очереди. K — удар пяткой v17a, L — экспериментальный круговой удар v18 (не полный пространственный разворот). Исходное комбо на 1 не настраивается этой панелью.

## Как пользоваться

- Выберите K или L. Нажатие соответствующей клавиши также переключает панель на эту атаку. У каждой атаки собственный профиль.
- Настройте четыре фазы (подготовка, выброс, возврат, восстановление). Время в кадрах симуляции 60 Гц, независимо от замедления. Кнопка «Выполнить атаку» эквивалентна нажатию K/L, в том числе для буфера после комбо.
- Целевая амплитуда масштабирует относительную цель голеностопа и вынос опорного бедра; длины костей не меняются. Цель ограничена досягаемостью, поэтому значение 110% не гарантирует 10% фактического прироста.
- Разворот таза масштабирует отклонение канала pelvis_turn от 45°; значения ограничены 0–90°. Полный поворот вокруг вертикали пока не реализован.
- Акцент ускорения меняет показатель степени кривой раскрытия конечности (1 + 0.65 × scale), сохраняя начало и конец фазы. Это не множитель силы урона.
- Выбор ноги: авто по опоре / принудительно ближняя / дальняя. Принудительный вариант — диагностический; при неудобной фазе бега может требоваться новая опора.
- P — пауза, N — один такт, 1× / 0.5× / 0.25× / 0.1× — скорость просмотра. Пауза не запрещает постановку команды; N затем выполняет один такт.
- JSON → копирует настройки обеих атак. ← JSON читает их из буфера обмена. Сохраните текст вне игры, если хотите перенести параметры между сеансами. Сброс восстанавливает только выбранную атаку. R сбрасывает бойца и замеры, но не профили и не темп просмотра.

## Замеры

Траектория берётся из фактически решённого рига после каждого такта Training.step, не из художественных целей. Для K используется существующий прокси пятки, для L — точка на нижней части голени. Белый круг — текущая точка, жёлтый — точка на такте максимального авторского акцента (не обязательно фактическое попадание), голубой — выбранная опора. Зелёная линия — накопленная траектория последней атаки выбранного типа.

Скорость = длина смещения ударной точки за такт × 60; максимум скорости считается только за фазу выброса. Дальность = горизонтальное положение ударной точки относительно сохранённой опоры. Максимум считается до конца авторского возврата; отдельно отображается дальность на акценте. После завершения замер сохраняется; новый запуск той же атаки очищает его. Единицы — единицы рига, не пиксели экрана. Параметры, изменённые во время атаки, применяются только при следующем запуске; текущая атака не перестраивается. Буфер комбо использует профиль на момент фактического запуска.

## Техническая структура

`attack_tuning.gd`: валидация профиля, отображение новых фаз на исходный авторский таймлайн, масштабирование ключей. `attack_polish_panel.gd`: UI и JSON. K и L используют прежний общий исполнитель и MotionEntry. Времена окон контакта берутся из настроенных фаз. Стандартные значения сохраняют исходные фазовые границы и художественные цели v18: K 9/3/10/10, L 10/3/13/10. Разворот всего тела и новые атаки не входят в эту версию.

## Проверка

`python tools/check_attack_tuning_math.py` — независимый расчётный тест. `godot --headless --path godot --script res://tests/attack_polish_v19.gd` — нативный тест (в среде сборки не запускался). Также сохранены тесты v17a/v18 и v15. Визуальная проверка в Windows Godot 4.4.1 необходима, особенно для крайних параметров и принудительного выбора ноги из бега.
