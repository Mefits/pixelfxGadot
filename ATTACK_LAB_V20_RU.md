# Attack Lab v20 — сравнение траекторий и плечевой пояс

База: v19. В F4 выберите K или L. Бирюзовая линия — текущий замер, оранжевая — предыдущий завершённый замер той же атаки. Оранжевый круг обозначает её авторский акцент, жёлтый — текущий. Для сравнения траектории совмещаются по точке опоры (только перенос, без масштабирования или поворота). Если текущего замера нет, прошлая линия отображается на своей исходной позиции. K и L хранят историю независимо. Опция «Предыдущая» скрывает оранжевую линию. R сохраняет последний завершённый замер; незавершённое движение не заменяет его. История действует в пределах открытого стенда, не экспортируется и не сохраняется на диск.

«Разворот плеч» независимо масштабирует отклонение авторского канала shoulder_turn от 45° (0–150%, с ограничением результата до 0–90°). 0% — нейтральная проекция в художественных ключах, 100% — прежнее движение. Вход по-прежнему адаптируется из фактической позы, выход — в текущую стойку. Изменения профиля применяются к следующей атаке. JSON v20 содержит shoulder_scale; JSON v19 автоматически получает значение 1.0. Полное пространственное вращение остаётся отдельной задачей.

Проверка в Godot: `godot --headless --path godot --script res://tests/attack_compare_v20.gd`. Тест добавлен, но нативное исполнение в среде сборки недоступно. Предыдущие тесты сохранены.

## Автоповтор

Кнопка «Автоповтор» запускает выбранный профиль K/L на следующем доступном такте, затем повторяет атаку после её полного завершения и регулируемого отдыха 0,2–3,0 с (по умолчанию 0,6 с). Время отдыха считается в симуляционных тактах, а не по часам: замедление просмотра замедляет и повтор; пауза останавливает цикл. N продвигает один такт движения без запуска очередного повтора. Изменение профиля действует со следующего запуска; выбор K/L в списке меняет следующую повторяемую атаку. «Стоп повтор» отключает будущие запуски, не обрывая текущую атаку. Ручная атака, перемещение, прыжок, R, закрытие F4 или потеря фокуса отключают цикл. Повтор выполняется из фактической конечной стойки, без телепортации; для одной анатомической ноги выберите её явно. Задержка фиксируется при каждом новом запуске, не меняет тайминг уже выполняемого удара. Автоповтор выключен при входе в стенд. Пауза между атаками не включена в экспорт художественного профиля JSON.

Тесты: `python tools/check_attack_repeat_math.py` (арифметическая модель) и `godot --headless --path godot --script res://tests/attack_repeat_v20.gd` (повторы K/L с точным интервалом и без перекрытия, требует Godot). Нативный тест добавлен, но не запущен.
