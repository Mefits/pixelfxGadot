# v14 — бег и прыжок с разбега

Основа — полный архив Lab Double Jump v13. Изменения ограничены стендом T и его контроллерами. Исходные движения, форматы, гибридное ядро 091 и панель F3 не переписаны.

## Управление

- A/D (или стрелки) — прежняя ходьба.
- Shift + A/D — бег с разгоном. Отпустить Shift, продолжая держать направление — плавное торможение до скорости ходьбы. Отпустить направление — торможение до нуля, затем обычное восстановление стойки.
- Смена направления при беге: сначала гашение текущей скорости, затем разгон в другую сторону. Направление взгляда остаётся вправо; движение назад — отступление, не разворот персонажа.
- Space — прыжок, повторный Space — второй импульс. Shift в воздухе не добавляет скорость: берётся состояние мотора на момент первого нажатия.
- F3, P, N, F2 и R работают как в v13. Vx в нижней строке — подписанная горизонтальная скорость в единицах скелета/с (на подготовке к прыжку показывается входная скорость).

## Первые параметры для художественной проверки

| Параметр | Значение |
|---|---:|
| Скорость штатной ходьбы | 30 единиц/с |
| Максимальная скорость бега | 111 единиц/с |
| Ускорение | 300 единиц/с² |
| Торможение | 420 единиц/с² |
| Разгон с нуля до предела, 60 Гц | 23 такта (~0,38 с) |
| Торможение с предела до нуля | 16 тактов (~0,27 с) |
| Переход позы на беговой цикл | 8 тактов |

Это стартовые, не художественно принятые значения. Константы находятся в `godot/lab/walk_control.gd`. Обычная ходьба остаётся прежней; новое ускорение относится к бегу и выходу из него. Для бега используется уже находящийся в v13 дистанционный цикл `hybrid091/gait.gd` — фаза шагов зависит от реально пройденного расстояния. Для отступления используется та же календарная модель с обратными целями стоп и более закрытым корпусом; это первый вариант, требующий художественной проверки. Переходы выбирают ближайшую фазу по фактическим носкам. Стопы в опорной фазе имеют фиксированные мировые цели; на коротких переходах цели интерполируются.

## Наследование скорости

Первый прыжок считывает скорость непосредственно перед тем, как наземный мотор передаёт управление воздушному. Направленный прыжок из покоя по-прежнему имеет 64 единицы/с; при совпадающем направлении берётся максимум из 64 и текущей абсолютной скорости. Без команды сохраняется текущая скорость. Противоположная команда не разворачивает первый импульс мгновенно, а постепенно меняет скорость в воздухе. При беге подготовка дополнительно смещает корень вперёд с удержанием мировых целей носков; наклон в воздухе может быть сильнее. Высота и длительность по-прежнему определяются F3. Воздушное управление не снижает унаследованную скорость при удержании того же направления. Второй прыжок без команды сохраняет горизонтальную скорость; с командой может сразу изменить её направление, умножая доступный предел на прежний коэффициент второго импульса.

На ровном месте без препятствий при настройке 0,8 с горизонтальный путь в воздушной фазе: 51,2 единицы из покоя, 88,8 с полного разбега. Это +73,4%, без учёта короткой подготовки. На границах арены расстояние ограничивается. Груша блокирует наземный бег слева; как в v13, воздушное перемещение не блокируется грушей. Приземление сохраняет прежнее завершение v13 (стойка и нулевая наземная скорость); следующий такт уже принимает движение. Скользящее приземление с сохранением инерции, новая акробатика, отдельная анимация бега в M и перенос в Project N пока не добавлены. Камера v13 фиксирована.
