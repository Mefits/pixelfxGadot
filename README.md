# N 0.05 — гибридная реакция

Godot 4.4.1, GDScript, без зависимостей и DLL. Откройте project.godot, нажмите F5.

A/D — движение первого бойца; W — прыжок; Shift — бег; F — быстрый удар; H — тяжёлый. F2 — включить второго игрока (стрелки, вверх, Ctrl, K/L для ударов). Space — пауза; R — сброс; F1 — скелет и опорные точки; F3 — включить/выключить hitstop; F4 — гибридная/обычная реакция; T — сброс на дистанцию удара.

Это первый игровой стенд, с быстрым и тяжёлым ударами, ограниченной физической реакцией корпуса, головы и рук, пока без способностей и VFX. Проверяем ходьбу, бег, движение назад в стойке, прыжок, приземление и возврат к стойке. Бег пока с постоянной опорой (без отдельной фазы полёта). В reports — настоящие кадры Godot. Синий и рыжий — временные диагностические фигуры. См. docs/PLAN.md.

Тест: godot --headless --script res://tests/locomotion.gd
Графические кадры: xvfb-run -a godot --script res://tests/visual.gd (на Linux).

Подойди к противнику и нажми F. Проверяй промах с дистанции, контакт, возврат руки и отталкивание. Отдельный тест: godot --headless --script res://tests/jab.gd

Сравнение: T → H; F4 → T → H. Режим сохраняется при сбросе. Не полноценный ragdoll. Тест: godot --headless --script res://tests/hybrid.gd
