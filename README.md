# PixelFX Godot Toolkit

Portable Godot 4 VFX toolkit built around the original MIT-licensed [PixelFX](https://github.com/patch-gg/pixelfx). Original rendering is the reference, not an approximation. Development begins with exact offline two-buffer exports and a Godot player; interactive native runtime is a separate milestone.

See AGENTS.md and docs/ROADMAP.md for integration rules and acceptance gates.
