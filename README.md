# N 0.02 — боевая стойка

Godot 4.4.1, GDScript, без зависимостей и DLL. Откройте project.godot, нажмите F5.

A/D — движение первого бойца; W — прыжок; Shift — бег. F2 — включить второго игрока (стрелки, вверх, Ctrl). Space — пауза; R — сброс; F1 — скелет и опорные точки.

Это первый игровой стенд, ещё без атак, способностей, VFX и гибридной реакции на удар. Проверяем новую стойку по референсу, её 1.2-секундный цикл, ориентацию, опору и переход к перемещению. Синий и рыжий — временные диагностические фигуры. См. docs/PLAN.md.

Тест: godot --headless --script res://tests/locomotion.gd
Графические кадры: xvfb-run -a godot --script res://tests/visual.gd (на Linux).
