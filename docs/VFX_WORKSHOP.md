# VFX Workshop
Y opens the layered composer. Seven primitive types (lightning, sparks, glow, ring, slash, droplets, smoke), up to 12 ordered layers, editable start and lifetime, start/end size, opacity, speed, curve easing, color, count, angle, gravity, glow and offsets. Four example presets. Add/copy/delete/reorder. Click timeline or scrub; playback, loop, moving anchor, background and seed. Save/load JSON in user://vfx_presets. Existing original catalog and custom workshop remain separate.
Runtime: preload res://addons/pixelfx/composer/renderer.gd and preset.gd; load validated preset, create renderer, enable_acceleration(), call render(surface.painter,preset,time,anchors,floor_y,provider), then surface.present(). Anchors origin/hand/target are Vector2 positions in painter coordinates; provider(name,time) may supply recorded moving anchor positions for deterministic seeking. Follow uses current time, non-follow uses layer start. The preview is 240x160 at 2x nearest. CPU render timing excludes texture upload. Particles use analytic time evaluation and simplified floor deflection, not arbitrary level geometry; no node graph, arbitrary curve keyframes or original catalog parameter editing yet. Lightning uses existing PixelFX zigzag/stroke; other blocks are new procedural compositions over the existing painter, not exact ports of original effects. Count is capped at four for lightning. No automatic integration with combat events yet.
