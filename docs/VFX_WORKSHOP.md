# VFX Workshop
Y opens the layered composer. Seven primitive types (lightning, sparks, glow, ring, slash, droplets, smoke), up to 12 ordered layers, editable start and lifetime, start/end size, opacity, speed, curve easing, color, count, angle, gravity, glow and offsets. Four example presets. Add/copy/delete/reorder. Click timeline or scrub; playback, loop, moving anchor, background and seed. Save/load JSON in user://vfx_presets. Existing original catalog and custom workshop remain separate.
Runtime: preload res://addons/pixelfx/composer/renderer.gd and preset.gd; load validated preset, create renderer, enable_acceleration(), call render(surface.painter,preset,time,anchors,floor_y,provider), then surface.present(). Anchors origin/hand/target are Vector2 positions in painter coordinates; provider(name,time) may supply recorded moving anchor positions for deterministic seeking. Follow uses current time, non-follow uses layer start. The preview is 240x160 at 2x nearest. CPU render timing excludes texture upload. Particles use analytic time evaluation and simplified floor deflection, not arbitrary level geometry; no node graph or original catalog parameter editing yet. Lightning uses existing PixelFX zigzag/stroke; other blocks are new procedural compositions over the existing painter, not exact ports of original effects. Count is capped at four for lightning. No automatic integration with combat events yet.

## 0.16 — independent parameter curves
Optional per-layer `curves` dictionary in schema 1, channels size/alpha/speed/glow. Each contains 2–16 strictly ordered [normalized lifetime, absolute value] points, endpoints at 0 and 1. Piecewise-linear interpolation; speed integrated analytically for deterministic seeking. Legacy layers with no custom curves preserve old calculations. Default activation approximates previous eased size/alpha with nine points; speed and glow use two. Disable returns to untouched base parameters. Speed affects particle primitives only. Custom glow also enables a soft halo on slash. No changes to original catalog or C++ raster backend. Use the Russian graph: left click to insert or drag, right click removes inner points, endpoints keep fixed times. Gold cursor shows current layer lifetime. Headless and visual verification pending.

## 0.17 — continuous particle emitters
Optional `emitter` dictionary on sparks/droplets/smoke: rate (integer 1–64 births/s), life (.05–3 s), life_jitter (0–.8 fractional symmetric random variation), shape (point/disc/ring/line), radius (0–40 px; line horizontal). Layer duration is emission window; timeline displays a conservative maximum tail of life*(1+jitter) after shutoff. Birth j occurs at j/rate strictly before emission end; capped at 320 births per layer. All four curves evaluate on individual normalized particle age. Speed integral scales by actual life. Follow keeps particles relative to current anchor; off samples anchor provider at birth (requires historical provider for moving emitters). Old simultaneous bursts are unchanged. Fixed per-particle seed and direct evaluation allow arbitrary seeking. Added energy stream demo. Tests authored, execution pending.

## 0.18 — motion trails
New trail primitive requires a historical anchor provider. Samples aligned to layer start; up to 64 samples/s, 1.5 s history, bounded segments and 32 stamps/segment. Styles ribbon/electric/dots, width from size curve, opacity and glow from their own curves, age normalized over trail.life. World-space only; no fake motion for a static anchor. Break-distance rejects long discontinuities; no sampling beyond emission window; tail survives shutoff. Electric style adds deterministic spatial jitter (0–12 px), not a separate lightning physics system. Renderer reports trail_segments. Existing raster backend unchanged. No speed/collision/particle emitter for trail. Demo uses a curved moving hand. UI and runtime checks authored; execution pending.

## 0.19 — organic deformation
Two new types: tendril and organic_mass. Required organic dictionary: arms 1–8, length 4–96 px, wave 0–32 px, frequency 0–6 Hz, taper 0–1, pulse 0–.45, stretch 0–.65, aim bool. Tendrils use fixed roots, seeded phases and a smooth increasing sine envelope, optional target direction (not endpoint IK). Mass uses reciprocal stretch axes, radial ripples and overlapping discs. Size/alpha/glow curves evaluate on layer age. No speed, particle emission or collision response. Limits: 48 centerline segments per arm, 24 mass spokes. Shared PixelFX batch path; no new native code. Russian demo and inspector; tests authored, execution pending. Visual quality and performance not verified.

## 0.20 — geometric energy primitives
Five field types: shockwave, beam, vortex, orb, rift. Required field dictionary: thickness .5–12 px, length 4–160 px, aspect .15–1, rotation -720–720 deg/s, distortion 0–1, aim bool. Existing size/alpha/glow curves affect the form. Beam length is capped by target distance when aim is enabled; angle is an offset. Shockwave radius grows from size curve, vortex uses rotating spirals, orb uses layered discs and orbiting ellipses, rift has two deformed edges and a dark center. The shared painter is used for all draws, no screen distortion shader and no collision/game damage. Up to 8 arcs and 96 segments per arc; line width capped to 12 raster strokes. Russian inspector and 5 isolated demo presets. Legacy types unchanged; tests and previews authored, not confirmed executed.

## 0.22 — combat cue integration (development branch)
The Combat inspector tab assigns a validated snapshot of the current preset to charge, cast, strike, cross, heavy, kick, air_strike, impact or block. The bank is persisted in user://creature_vfx_bindings.json and loaded when combat resets. Missing roles retain the old effects. The runtime starts at existing authored event markers; hit/block cues use the resolved contact. Origin/hand alias the marker limb, target is the fixed target captured at the cue. Follow and trail layers sample actual limb history at fixed 120 Hz simulation ticks; hitstop pauses this clock. Facing is fixed at spawn and painter mirrored accordingly. Multiple effects append to the same painter without clearing earlier pixels. Cap 12 active instances and 2048 samples each; overflow falls back to the old effect. No new damage or collision logic. This is role-level binding, not yet per-marker editing or a visual event timeline. Tests authored, not executed; do not change tested 0.21 branch until feedback.
