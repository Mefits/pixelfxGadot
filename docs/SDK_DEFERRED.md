# SDK — отложенная приёмка

Дата решения: 2026-11-24. Владелец проекта не планирует использовать SDK в ближайшее время и не должен сейчас тестировать его вручную. Не расширять SDK и не запускать отдельные GitHub Actions ради его приёмки до появления реального сценария использования. Сохранять существующий код и данные.

## Статус
- Последняя полностью зелёная версия: v0.30, f63f0e78378436d46c673210c70b6b0b3a8a9da3, https://github.com/Mefits/pixelfxGadot/actions/runs/45466799404.
- SDK v0.35: 352fd0c32a261e5dd455088331fd36777735e894, https://github.com/Mefits/pixelfxGadot/actions/runs/45468563664. Общий CI завершился failure, не считать v0.35 проверенным релизом.
- Прежние регрессии, 37 шаблонов в обоих валидаторах и пять независимых экспортированных примеров прошли. В частности, ошибка числового enum v0.31 исправлена и проверена.
- Black-box тест остановился на tools/test_creature_sdk.py:52: шестиногий мутант (6 ног, 2 щупальца по 5 звеньев, хвост 4, масса 1.4) успешно запустил grab, но hits=0, target_moved=0; finite=true, max_penetration≈0.00000305 px, max_constraint_error≈0.07127 px, max_support=6. Причина отсутствия контакта пока не установлена. Последующие проверки black-box (повтор, захват кадров, GIF/contact sheet, парный экспорт) не выполнены в этом запуске.
- Независимая приёмка другой моделью ИИ, визуальная оценка и практическая интеграция в игру не проводились. Не выдавать автоматический тест за независимую приёмку.

## Когда вернуться
При первом реальном использовании SDK воспроизвести неудачный grab через публичный CLI, диагностировать траекторию кончика и условия захвата, устранить причину без ослабления критерия hits/target_moved. Повторить полный black-box сценарий и дать sdk_acceptance/BRIEF.md новому агенту без истории разработки. Визуальную оценку проводить только по реальным кадрам. До этого SDK остаётся экспериментальным.

## Текущий приоритет
Отложить дальнейшее развитие SDK. Предлагаемый следующий блок по дорожной карте — удобство GUI: простое/расширенное представление, навигация, читаемость, рабочие процессы создания и редактирования. Конкретные изменения согласовать отдельно. Сохранить проверенный runtime и не менять тестовую EXE v0.26.
