# Стенд управления — первая итерация

T теперь открывает стенд одного персонажа. A/← назад, D/→ вперёд, отпускание останавливает перемещение, обе клавиши одновременно нейтраль, R сброс, Esc меню. Персонаж всегда смотрит вправо. Атаки, противники и Box2D не участвуют. Старый стенд двух манекенов сохраняется в исходниках и тестах, но не открывается из меню.

Для этой первой проверки используется принятый процедурный цикл ходьбы Astra и его обратная выборка по знаковому расстоянию. Это экспериментальная обвязка, а не новый художественно принятый задний шаг. Остановка опускает свободную стопу и расслабляет корпус без перемещения корня. Ядро Astra, формат движений и исходные клипы не изменены. Следующая задача после пользовательской оценки — выбрать отдельные редактируемые позы для стойки и двух направлений, не переносить автоматически плотные ключи.

В M добавлено подтверждаемое удаление пользовательских документов. Встроенные sprint/jab/feint защищены.

## Вторая итерация: авторские движения
M: три первые позиции — Стойка (один ключ), Ходьба вперёд и Ходьба назад (8 уникальных ключей + связанный конечный ключ). Режим FK для всех костей; правка первого/последнего ключа синхронизируется. Сохрани Ctrl+S, затем открой T: сохранённые документы загружаются автоматически. Длительность циклов задаёт скорость при фиксированной длине цикла 32 единицы. Задний цикл и передний редактируются независимо. IK-цели атак, VFX и release-окна здесь не применяются. Режим 3 показывает тот же алгоритм контакта, что и T в установившемся движении. Контакты ног пока имеют фиксированные фазы; при стопе корень прекращает перемещение сразу, стопы по очереди переставляются за 16 тиков в сохранённую стойку. При старте и смене направления — 10 тиков смешивания, подлежит художественной проверке. Нативное ядро Astra не меняется. Старый sprint остаётся процедурным.
