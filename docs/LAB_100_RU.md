Текущий CI и ручная приёмка интерфейса ещё не подтверждены; см. Actions Lab 1.0 RC1 integration. Не выдавать исторические архивы за RC1.

## Запуск и инструменты

Godot 4.4.1 x86-64, импорт `godot/project.godot`. Для H нужен нативный PixelFXBodyRaster: `python native_cpp/build.py` (Python, SCons, Git и компилятор). При отсутствии расширения H показывает диагностику и позволяет вернуться в меню. Для исходных PixelFX-эффектов остаётся прежний setup (Node.js 18+, npm run bootstrap).

- H — новый стенд «Гибридное движение»: Astra Hybrid 0.91, 069 C, 090 C, с общей растеризацией. Кнопки/1/2/3 задают остановку, ходьбу, бег; F/G/K — джеб, кросс, удар ногой. J/B/N — простой импульс Astra; не реальный контакт. Space пауза, → один тик, R сброс, Esc меню.
- Выбор режима «Реакции 0.92 C (отдельно)» переключает на сохранённый эксперимент: J голова, B корпус, N сильное попадание с разрешённым шагом. Это не интеграция реакций в ядро и не бой.
- Ткань: выключена/B/C, ветер −180…180, 2 визуальных подшага на игровой тик 60 Гц. Движущиеся мировые крепления и грубые прокси головы/корпуса; ткань не участвует в контактах и rollback. Новая проверка движущихся креплений, не художественная приёмка. Оба материала сохраняются.
- U — прежний редактор ключевых клипов, T — прежний бой двух персонажей, I — прежняя физическая лаборатория. Y/J/A/L — прежние PixelFX инструменты, каталог шаблонов и экспорт сохранены. Новая сцена не подменяет старый редактор и не заявляет общий формат авторинга.
- 1.0 RC1 — версия интерфейса сборки; номера 069, 074, 090, 091, 092 — версии экспериментов, а не последовательные релизы приложения.

## Единая мастерская движений
M является основным рабочим редактором: IK/FK/исполнение в одном окне, root XY, авторская сетка 24/30/60 fps, интерполяция, цикл, события и PixelFX VFX preview. Встроен импорт банков U в формат Astra; U оставлен для совместимости. H перемещён в диагностику ядра/ткани, P/Box2D — в разработку. T остаётся отдельным стендом двух бойцов, Y — специализированной мастерской эффектов. Проверка пакета выполняется после холодного скачивания, до пользовательской приёмки.

### Интеграционная проверка мастерской (кандидат)
Основное рабочее окно — M; T читает сохранённые нециклические действия из общего каталога формата Astra. H — дополнительные диагностика, ткань и реакции, U — сохранённый прежний редактор, P — отдельная физическая мастерская, не участник авторских атак. Переход на формат v2 и импорт U требуют отдельной проверки; перенос углов не означает совпадения конечной позы на другом риге. Сборка пригодна для передачи тестерам только после preflight, Windows/Linux, replay, UI и проверки скачанного Windows-пакета. Не считать зелёный промежуточный тест финальной приёмкой.
