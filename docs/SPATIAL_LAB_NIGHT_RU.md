## Архитектурное решение Astra и уточнения
Сохранить старый 2D execution path без изменений. Опциональный spatial pose: стабильные анатомические ID, immutable rest_offset_xyz, joint_xyz и joint_basis, point3(id), point(id) = projected XY, полный знаковый yaw int64 (65536/оборот), relative chest/shoulder twist, свободная конечность optional azimuth. X вдоль арены, Y вниз, +Z к камере; фиксированная композиция FK. Не отождествлять старые pelvis_turn/shoulder_turn 0–90 с yaw. Проверить длины и точность адаптации старой позы; несовместимость не скрывать. Опора world anchor_xyz, free/pivot/fixed; двухзвенный IK с сохранением плоскости колена, разрешение недосягаемости/двойной опоры. MotionEntry переносит полный yaw, XYZ, приращения, контакты; переход через 360 без wrap, отмена на 180 без snap. PixelFX: сначала проверить существующие triangle surfaces с нормалями и Z-buffer, включая почти осевую кость; не переписывать аналитический loft без необходимости. Сохранить материалы, part IDs и свет, выключить декоративные Z offsets только в spatial режиме. L сохраняет сроки, поверхность distal shin (0.9 knee→ankle), старое L контроль. Глубина игровой коллизии отдельное исследование: не менять авторитетные 2D правила без решения владельца; сравнить альтернативы отдельно. Выборочная физика и стилизация после игровой позы. Integer yaw не гарантирует cross-platform determinism: фиксированный порядок, округление, snapshot, replay и cross-platform hash; не утверждать детерминизм без проверки.
