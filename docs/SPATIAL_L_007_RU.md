# Spatial Lab 0.07 — хореография L
Владелец принял 0.06 как техническую основу, визуальная полировка необходима. База 55ca19f1f7d4441f8a59c8f6bea8340f14f25c70; экспериментальная ветка experiment/spatial-lab-007. A точный контроль 0.06, B умеренный, C динамичный, D анимешный. Все параметры художественные гипотезы. У всех старый тайминг, один оборот, исходный контакт голенью, одинаковая IK и MotionEntry; прежний Training не меняется. Никаких смазов, света и эффектов. Пространственные изменения: монотонная кубическая интерполяция yaw между ключами (не принудительная остановка на каждом ключе); независимые относительные запаздывающие скручивания груди и плеч, азимут свободной ноги и рук, небольшой кинематический перенос таза к опоре после вычисления orbit, с сохранением toe anchor через прежний IK. Никакой физической модели равновесия/стопы, не претендуем на анатомическую правильность. Ударный кадр yaw 0, конец signed 65536. Траектория и диагностический XY контакт могут различаться; не менять авторитетные правила. Риг/FK/IK/растеризатор без изменений, два расширяемых метода в roundhouse имеют прежнее поведение по умолчанию; профили только в subclass. Контроль проверяется сравнением current/diagnostic с исходным классом на каждом такте. CI: старые L005 и replay006, 24 варианта (4x2 ноги x3 входа) 912 тактов, длины, опора, замороженный профиль, checkpoint roundtrip, нативная растеризация всех 296 default frames, метрики угловой скорости и шага/второй разности точки удара, смещения таза; мобильные 2x2 GIF 1x с финальной паузой, MP4 0.25x (37 source frames), key PNG, фиксированный общий crop. Технические результаты только после CI. Художественный выбор владельца.
