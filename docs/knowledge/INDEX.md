## Накопление опыта

- [OPEN_GAME_INDEX_RU](OPEN_GAME_INDEX_RU.md) — полный исходный исследовательский индекс. Тематические файлы — его начальная декомпозиция; новые знания вести в тематических файлах, исходный индекс сохранять как исторический снимок.

## Обязательный порядок для чата / агента

1. До изменения кода определить репозиторий, ветку и HEAD, прочитать её AGENTS.md, handoff и проверить актуальное состояние CI. Старый пример ветки в документации не переопределяет явно выбранный эксперимент.
2. Открыть этот INDEX на main отдельно от экспериментальной ветки; выбрать раздел по задаче. Для визуальной работы также OG-04; для игровых изменений OG-05; для handoff OG-12.
3. Сначала проверить существующий механизм и совместимость с принятыми решениями. Разделять внешнее предложение, технический pass, художественную приёмку и фактический PvP.
4. Выполнить проверки по рискам, зафиксировать SHA, команды, метрики, артефакты, известные ограничения. Не выдавать зелёный CI за визуальную приёмку. Не запускать избыточный CI.
5. После существенного нового воспроизводимого результата обновлять тематический раздел или журнал, с источником и статусом. Не мержить активные ветки ради документации; при параллельной работе сохранять чужие изменения и использовать non-force CAS.

Обычный новый чат не гарантирует автоматического чтения GitHub. Достаточная стартовая фраза: «Работай по N-KB: https://github.com/Mefits/pixelfxGadot/blob/main/docs/knowledge/INDEX.md».
