# Lab 0.99 — сравнение трёх физических движков
Владелец: не разрабатывать новый физический движок без необходимости. Сравнить собственный решатель, Godot и Box2D. 098 показал устойчивость при импульсах ×1/3/5, но ошибочно масштабировал вертикальную составляющую для прямого удара. База 41ab07230432bd411e1d649f2ae5db76cd8309c2, CI 45906430269, artifact 15158321664. 098 и прежние ветки сохранены.
## Общий тест
A: решатель 097 (копия для общего протокола; фиксированное трение .22, без прежнего предписанного spin/launch, без ограничения угловой скорости). B: RigidBody2D/PinJoint2D Godot Physics 4.4.1. C: настоящий Box2D 3.1.1 C API, отдельный исполняемый файл C++ для исследования, не интегрированная игровая библиотека. v3.1.1 tag в CI, точный SHA печатается. MIT. Общее исходное положение из проверенного guard, 15 сегментов, одинаковые массы, моменты инерции, круговые proxy формы, точки шарниров, плоский пол, gravity180, damping .9, трение .22, нулевой отскок, self collision отключена и сон отключен для сопоставимости. Box2D масштаб .05 м на art unit, импульсы/инерция масштабируются соответственно. Сразу один горизонтальный импульс J=(-90*суммарная масса,0) в конкретную точку груди; не вводить вертикальную скорость, отдельное вращение или локальную анимацию попадания. Угловой импульс только от плеча силы и суставных реакций. Общая авторская цель и ограниченные парные суставные моменты, 0.06–0.24s затухание, остаточная жёсткость и мягкий stop, C++ порт той же формулы. Сохранять A/C hard limits; Godot PinJoint2D 4.4.1 native limit отключен намеренно: исходник modules/godot_physics_2d/godot_joints_2d.cpp вычисляет угол линии между центрами тел относительно начального угла в мире, не угол между костями. B использует тот же общий bounded angular stop, оценка фактического нарушения угла отдельно. Это честно обозначенная разница возможностей/адаптеров, не доказательство идентичности решателей.
## Проверка
120Hz, 600 подшагов, две независимые симуляции каждого backend в разных процессах, сравнение численных состояний без таймингов. Fresh-start repeatability не rollback; Box2D 3.1.1 не приписывать snapshot API из более новой ветки; Godot также не гарантирует межплатформенный детерминизм. A 28 итераций; B штатные настройки Godot; C один native подшаг на 1/120; это сравнение текущих конфигураций, не равное число итераций. A/C p95 controller+solver, B монитор всей physics process + отдельное время controller, не напрямую сопоставимая чистая стоимость. Общий PixelFX native render 60Hz после записи траекторий (не входит в timings), 18 статических кадров до удара, GIF ×1/×0.5. Измерить COM, высоту, зазор шарниров, floor penetration, относительные углы, разницу физика/FK, остаточную скорость. Quality gate отдельно на backend, даже если плохая дорожка визуализируется; CI success означает завершение сравнения, не автоматическую приёмку всех движков. Нет финальной позы, самоколлизии, реального попадания двух бойцов, теста rollback или производственного бенчмарка. Astra, Project N, main и старые решатели не меняются.
