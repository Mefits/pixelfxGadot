# Aura Lab 0.01 — живая энергетическая оболочка

Ветка experiment/aura-lab-001, база b76369f76ff402a120ba8734b42fe27a69a1f57d (Ability Lab 0.01, проверенный CI 46147265729, код ad55147b). Отдельный опыт, без merge и без изменений исходных Combat/Ability/Spatial/Choreography или Project N. Владелец одобрил направление Ability 0.01, попросил больше дистанции и исследование энергетических конечностей/ауры по референсу оранжевой оболочки с хвостом. N-KB OG-02/04/05/12.

Гипотеза: живой визуальный аватар может следовать за реальной геометрией тела, не вмешиваясь в игровой риг. Используем точную маску существующего PixelFXBodyRaster (069 C, Hybrid091) и native Painter (blend, circle, dot, add, glow), отдельные color/light. Изучен composer/organic.gd: волновая ось, taper, pulse; его свободная органическая геометрия подходит для хвостов, но не повторяет тело, поэтому здесь вторичная цепь следует реальному тазу и растровая маска расширяется chamfer-расстоянием. Это оригинальная композиция из имеющихся технологий, не заявка на faithful upstream port. Не новый игровой solver.

0 контроль без ауры; A cloak — облегающая пульсирующая оболочка; B tail — более выразительный силуэт и один инерционный хвост; C twin — большая оболочка, два хвоста. Одинаковые палитра, 60 Hz input trace, масштаб 3x, фиксированная камера 792x360, стартовый gap 84 art px (вместо 26–32 в предыдущих захватах); не изменение баланса Ability. Движение, остановка, удары/реакции по реальному Combat World; никаких принудительных попаданий. Визуальное состояние сбрасывается при reset. Для rollback нужен отдельный reset/replay визуального слоя; не входит в авторитетный snapshot. Декоративные хвосты сейчас не имеют hitbox.

Проверки: native raster oracle, фактические Godot PNG, равенство авторитетных snapshot на каждом тике четырёх вариантов, отсутствие записи в World, повтор кадров после сброса, реальные контакты записаны, отдельные p95 симуляции/тела/ауры и max ауры, 180 исходных PNG на вариант, GIF 1x, MP4 60fps 1x/0.5x, ключевые кадры. CI и ручной визуальный осмотр ещё не завершены. Не утверждать качество и оптимальность до артефактов. Scene res://lab/aura_study_001/scene.tscn (0–3 / R).

Дальше: три фактических цикла render/inspect/refine, выбрать выразительность по владельцу, затем Aura 0.02 — увеличенная рука вокруг руки, затем 0.03 — вытягиваемая рука/траектория и реальный контакт через Ability World. Песок, тень и прочие материалы отдельно. Ability 0.02 — отдельная полировка, включая удержание клинка, полный лимит рывка и более свободную дистанцию; эта ветка не изменяет её механику.
