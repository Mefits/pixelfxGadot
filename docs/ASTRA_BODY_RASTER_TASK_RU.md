# Astra — узкая задача: нативное ядро рендера персонажа (Lab 0.54b)
Дата 2026-11-25. Ветка experiment/astra-body-raster-054. База dfd74b933c858e78926168e1d0cef98cf3168528. Владелец выделяет ограниченный дорогой запуск Astra только на сложную техническую часть. Цель: универсальный рендер, который принимает УЖЕ вычисленную позу любого нашего клипа. Не делать новые анимации/арт, не переделывать IK, не менять Project N или исходный upstream, не вливать в рабочую ветку.

## Один сфокусированный рабочий цикл
1. P0: отделить geometry raster от solve; C++ kernel + Godot callable bridge, строгая проверка входов, per-pixel depth, deterministic sphere/sweep/ellipsoid, shared buffers. Reference mode соответствует алгоритму upstream на primitive fixtures; не переписывай rig.js целиком.
2. P0: нативные тесты ядра, совпадение с oracle на малых сценах; Godot smoke, покажи минимум сложных поз на неизменённом FK, зафиксируй время и ограничения.
3. P1: organic mode, группировка соединённых объёмов, без косметических швов, регулируемая гладкость (не глобальное слипание пересечённых конечностей), палитры и density. Если ресурсов не хватает, сохранить законченное P0 и явный интерфейс для P1; не жертвовать корректностью ради количества вариантов.
4. Handoff: commit/branch, файлы и команда сборки, actual test results, интерфейс, benchmark, нерешённое. Не merge. Sol продолжает адаптер под суставы, радиусы, форму, волосы, одежду, визуальный review, новые анимации. Не расходовать лимиты на эти задачи.
