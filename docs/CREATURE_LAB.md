# Animation & Creature Toolkit — first vertical slice
New independent addon godot/addons/creature; existing PixelFX sources and binaries remain unchanged. The first stage is a data-driven 2D joint graph, local-angle poses, CCD IK for any chain, JSON clips, marker-based strikes and casts, and replaceable prototype skin. This is not the original PixelFX 3D rig, and not Rain World physics yet. The separate graph/skin makes arbitrary limbs and later physical constraints possible.
Open Pose Workshop (U) in the main PixelFX lab; choose a clip, drag a joint (hands/feet have chain limits), edit local angle/root, scrub and Set key. Set duration rescales key/event times. Add event uses selected joint as anchor; Save writes user://creature_clips.json. Arena reads that file at reset. Changes to pose are not committed until Set key. Tab in arena opens editor. T opens arena from main. P1 A/D/W/F/G/S; P2 arrows/K/L/Down; B toggles bot; R resets. V shows bones. Both fighters use the same animation bank, different tint. Attack events test actual hand range, spell events test direction/range, guard reduces damage. Prototype visual skin is intentionally replaceable; not final art.
Next: joint limits and independent animation banks, hitbox windows, transitions, physical body solver (segments with mass, contacts, constraints), then blend physically reachable IK goals with authored poses. Do not couple movement to rendered polygons.
