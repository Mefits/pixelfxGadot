# Адаптивные атаки v7

`godot/lab/attack_adaptation.gd` — отдельный слой исполнения. Он не изменяет авторский документ и не зависит от номера атаки. `bind(doc, rig, entry, previous_lead)` фиксирует роль, переназначение и события на границе действия. `sample(doc, time, rig, binding)` выбирает позу. `prepare_pose` используется отдельным временем подготовки при несовпадении требуемой и текущей стойки. `training_control.gd` использует переназначенный strike-anchor для расчёта контакта.

## v7: отдельное завершение удара

`attack_recovery.gd` рассчитывает необязательный план приземления после окна контакта. Политика `landing_policy: forward_land` доступна для однофазного FK-удара ногой. На исходном третьем ударе включена по умолчанию; новые ID по умолчанию `authored` и могут явно включить политику. Роль `authored` всегда сохраняет полный клип. Проверяются неподвижность опорной ноги, наличие воздушной фазы, первое устойчивое приземление и отсутствие нового движения стоп в хвосте. При несовместимости, нестандартной ширине стойки или выходе за пределы арены исполняется весь исходный клип.

Для оригинального удара контакт происходит на локальном такте 12, конец окна — 14, первое устойчивое касание — 26, конец клипа — 38. После окна контакта плавно перенаправляется горизонтальная координата ударной стопы на переднюю точку стойки; вертикальная траектория исходного спуска сохранена, корень подстраивается, ноги решаются IK. Стопа опорной ноги сохраняет мировую координату в фазе спуска. После приземления новая пара опор совпадает с шириной стойки, локальная система координат переопределяется без скачка мировых суставов. `training_control.gd` возвращает управление на границе приземления, а не в конце авторского файла. Движение по удерживаемому направлению начинается на следующем такте; новое нажатие атаки можно принять сразу после освобождения. Обычный переход к Idle продолжает работать без блокировки. На тренировочной груше прежнее ограничение движения вправо остаётся действующим.

Настройка: M → Комбо 3 → Движение → «Финиш: шаг вперёд» или «Финиш: авторский», сохранить документ, T → R. M показывает исходные ключи; адаптивный финиш виден в T. Исходные точки контакта и ключи клипа не перезаписываются.

## v6: независимое назначение рук и опоры

`bind` вычисляет `swapped` для ударной конечности и `legs_swapped` для ног. Для неавторского удара рукой порядок ног определяется фактическими носками на входе, а не выбором руки. `stationary_support` проверяет все авторские ключи (допуск 0,05 единицы) и обе опоры на земле. Если вход тоже заземлён (допуск 0,35) и ноги не перекрываются, `planted` фиксирует реальные координаты носков на весь удар. Исходное движение таза относительно середины опоры и позы рук сохранены; корень дополнительно корректируется при недостижимой IK-цели. Не применяется по номеру атаки: новый стационарный FK-удар рукой получает ту же логику. Вход из шага, подвижная опора, удар ногой и явный режим `authored` оставляют обычный переход. До фазы завершения третьей атаки сохраняется v5; короткое согласование с клипом удара ногой может перемещать стопы.

В T видны роль и фактическая ведущая нога; F2 включает метки БЛ/ДЛ. Если неожиданно видна роль `authored`, её можно сменить в M, сохранить и перезагрузить T. Сохранения пользователя не удаляются и явно выбранные роли не переписываются.

## Контракт документа

Поддерживаются полные FK-документы боевого стенда версии 2: `kind: action`, `training_attack: true`, полный набор 15 каналов, `loop: false`, один strike-маркер кисти либо стопы, без IK-целей и release. `limb_role` — необязательное поле:

- `auto`: сохранить функциональную роль авторской конечности относительно исходной стойки.
- `leading`: сторона фактически передней ноги в начале движения.
- `trailing`: сторона фактически задней ноги.
- `near`, `far`: конкретная анатомическая сторона независимо от стойки.
- `authored`: исходное назначение без переназначения.

Для исходных комбо без поля действуют значения leading/trailing/trailing (в том числе старые сохранения). Для нового ID значение по умолчанию auto. Роль рук определяется по стороне ведущей/задней ноги; независимое определение ведущей руки не введено. При разнице x носков не более 0,6 используется последняя определённая ведущая нога. Приоритет явного выбора может потребовать подготовительного шага.

## Подключение новых атак

Создать полный документ по образцу `Punch.default_doc()` в `training_punch.gd` либо экспортировать подготовленный полный FK-клип с указанным контрактом. Сохранить его как `user://motion_authoring/<id>.json` (id должен совпадать с именем файла). Для использования в T создать `user://training_loadout.json`, например:

```json
{"slots":["combo_original_1","combo_original_2","my_new_kick"]}
```

Пустые, отсутствующие или невалидные слоты автоматически заменяются исходными атаками; файл не обязателен. В коде тестов документы можно передать в `Training.new({3: my_document})`. T → R перечитывает документы. В M можно редактировать существующий валидный training_attack и его роль; отдельный мастер создания таких документов/выбора слотов ещё не добавлен. Обычные Astra-документы со смешанным процедурным управлением и IK-целями пока не пропускаются через новый слой. Интеграция с ними требует отдельной реализации.

## Ограничения

Переназначение проверено на геометрии боковой проекции. Фактическая глубина и художественное качество нативного рендера, достижимость всех промежуточных IK-целей и отсутствие скольжения в коротком входном смешивании требуют проверки в Godot. Нативные тесты в архиве не запускались в среде сборки. Новая подготовка при фиксированной конфликтующей роли намеренно добавляет 16 кадров до исходного клипа; для обеих обычных функциональных стоек полное авторское комбо занимает 76 тактов; v7 с адаптивным финишем — 64 такта при совместимом приземлении.
