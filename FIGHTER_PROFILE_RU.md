# Профиль бойца — v8

Задача: отделить настройки персонажа от исполнения движений, не создавая новую подсистему анимации. Текущий боевой стенд сохраняет механику v7.

## Один файл настроек

`godot/lab/profiles/default_fighter.json`:

```json
{
  "body": {"id": "lab_humanoid_069", "rig_preset": "humanoid_069"},
  "guard": {"id": "standard_guard", "width_scale": 1.0}
}
```

`body` определяет используемый комплект скелета и тела. В v8 единственный поддерживаемый `rig_preset` — `humanoid_069`. `id` — идентификатор, не новый скелет. `guard` задаёт параметры стойки. `width_scale` — множитель расстояния между опорными носками относительно авторской стойки: 1.0 без изменений; 1.10 на 10% шире. Диапазон 0.85–1.15 ограничен намеренно. Некорректное значение заменяется стандартным или ограничивается диапазоном. После сохранения JSON нажать R в боевом стенде T, чтобы перечитать профиль. M по-прежнему показывает авторские движения, не масштабированное исполнение.

## Что связано с профилем

- `fighter_profile.gd` загружает настройки, создаёт прежний скелет и тело, масштабирует цели контактов относительно середины стойки.
- `walk_control.gd` применяет одну ширину в начальной стойке, Idle и восстановлении после движения; порядок ног остаётся адаптивным.
- `attack_recovery.gd` использует тот же `guard_intent` для ширины посадки после удара ногой. Не создаёт отдельную фиксированную ширину для атаки. Момент окончания v7 сохранён.
- `training_control.gd` принимает необязательный профиль при создании экземпляра. Исходные JSON атак не изменяются.

## Границы этапа

Ширина цели приземления и стойки общая, но это ещё не универсальный ретаргетинг: траектория авторской фазы удара и ходьбы не масштабируется полностью под ширину, а геометрия иных тел не поддерживается. При новых пропорциях потребуются пересчёт досягаемости, контактов и проверка отрисовки. Не добавлялись параметры массы, роста, классы бойцов, выбор профилей в интерфейсе или новые анимации. Следующий этап — прыжки и приземления с текущим скелетом, затем другие базовые перемещения.
