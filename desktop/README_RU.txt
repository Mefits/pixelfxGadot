Creature & PixelFX Toolkit v0.26 — Windows x64

Распакуйте ВЕСЬ архив в отдельную папку и запустите Creature_PixelFX.exe.
Устанавливать Godot не нужно. Не переносите EXE отдельно от DLL: нативный модуль PixelFX нужен для каталога оригинальных эффектов и ускорения.
Файлы проекта уже встроены в EXE.

Y — конструктор эффектов
U — редактор анимаций
T — боевая лаборатория (E — способность, Q — настройки)
I — физика и эволюция
J — оригинальный каталог PixelFX
Esc — главное меню

Программа без цифровой подписи; Windows может показать предупреждение SmartScreen.
Исходная версия: a0d227c2ac283e83681220761cf3784d00c5f7a6.
